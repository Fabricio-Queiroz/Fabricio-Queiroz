## O que eu resolvi

Cada linha aqui começou com alguém travado. Não é projeto de portfólio — é código que roda todo dia.

**O peticionamento eletrônico recusava os PDFs assinados.**
A plataforma de assinatura deixava campos de formulário que o tribunal não aceitava.
Escrevi o [Achatador de PDF](https://github.com/Fabricio-Queiroz/achatador-de-pdf): remove os campos e a assinatura, mantém o texto pesquisável e roda offline — documento sigiloso não sai da máquina.
`Python`

**Juntar holerites à mão consumia horas todo mês.**
Dezenas de PDFs para unir e renomear na ordem certa de competência.
Fiz o [Automatizador de Holerites](https://github.com/Fabricio-Queiroz/automatizador-de-holerites): app Windows que faz isso em segundos, não exige Python instalado, com 29 testes garantindo que a ordem nunca sai errada.
`Python`
